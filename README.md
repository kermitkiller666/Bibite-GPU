# Bibite GPU Fork

This repository contains the **0.6.9 release-candidate mod source** in
[`0.6.9/`](0.6.9/). It does not include The Bibites game, its Unity assets,
BepInEx binaries, a launcher, or save files.

Start with the [0.6.9 README](0.6.9/README.md) and
[installation notes](0.6.9/INSTALL.txt). The mod currently targets a
user-supplied Windows x64 copy of **The Bibites 0.6.3.1**; it has not been
rebased or verified against the upstream 0.6.4 game.

This is a release candidate, not a finished public binary release. The
[publication checklist](0.6.9/COMMUNITY_RELEASE.md) records remaining live
tests and compatibility limits. No source-code license has been selected yet.
